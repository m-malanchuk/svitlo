# Changelog

All notable changes to Svitlo are documented in this file.

## 0.1.0 - Unreleased

### Added

- Today and tomorrow outage schedules for ZOE queues.
- A 24-hour outage timeline with queue selection.
- Local schedule caching and manual refresh.
- Configurable periodic background refresh.
- Schedule-change notifications.
- Russian and Ukrainian interfaces.
- Optional 30-minute schedule correction.

### Compatibility

- Android 10 (API 29) or newer.
